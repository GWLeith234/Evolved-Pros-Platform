## PR #13 — Home card & data consistency (Sprints 1–6)

Parsed a design brief into six sprints, executed as parallel sub-agents in
isolated worktrees, integrated in dependency order.

- **Sprint 1 — Card anatomy:** one `TileCard` shell + shared `TileRow` /
  `TileFooterLink`; unified header grammar (eyebrow · sentence-case title ·
  `N NEW` pill), one row template, one `ALL … →` footer across the four top tiles.
- **Sprint 2 — Data formatting:** new `lib/format.ts` (relative time, dates,
  counts, pct, episode #, duration, trend); all home formatting routed through it.
- **Sprint 3 — Progress de-dupe:** single `PILLARS` source in `lib/pillars.ts`
  (one order 1→6, one abbr scheme); Foundation metrics reconciled; duplicate
  "Path Forward" heading removed.
- **Sprint 4 — Metric display:** Bebas Neue numerals (off Playfair); `formatTrend`
  chips (flat = `— 0% wk`); uniform hero stat strip.
- **Sprint 5 — Surfaces:** the two rogue light cards → tokenized dark surface.
- **Sprint 6 — Copy hygiene:** `lib/brand.ts`; fixed `EVOLVED · EVOLVED` and
  the `→ →` double-arrow; activity-feed icon taxonomy.
- **Follow-up:** tokenized the remaining light surfaces on the render path
  (`GoalCard`, `PillarJourneyStrip`, empty-goals card) and fixed
  `AcademyProgressWidget` rendering dark-navy text on a dark surface.

Note: surfaces follow the theme (`--bg-surface` is dark in dark mode, white in
light mode via `html.light-mode`). The page is dark by default.
