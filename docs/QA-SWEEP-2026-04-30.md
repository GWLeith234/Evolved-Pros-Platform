# QA Sweep — Platform UX & Performance Sprint

**Date:** April 30, 2026
**Branch:** `claude/init-evolved-pros-platform-Q2oUw`
**Range:** `8fa536e..9b49557` (8 commits, ~12 hours of work compressed)
**Result:** all 8 deferred items from the original QA report shipped.

---

## TL;DR

A read-only QA sweep across the entire platform identified ~25 issues across navigation, forms, accessibility, performance, and visual consistency. Eight follow-up items were prioritized and landed as `UX-0` through `UX-7`. The largest single win was a **−75% First Load JS reduction on `/podcast/[slug]`** (389 kB → 97.9 kB) via lazy-loading the Mux player. The largest UX win was making the admin surface usable on mobile and giving direct messages real send-state feedback so users can finally tell whether their message was delivered.

---

## What landed

### UX-0 · Quick wins (initial pass) — `8fa536e`

Before starting the formal sprint, four high-impact / low-risk fixes shipped together:

- **Route-level skeletons** for `/community`, `/messages`, `/notifications`, `/events` — replaces blank/spinner navigation with editorial-shape skeletons (`PostSkeleton`, `NotificationSkeleton`, `EventCardSkeleton`).
- **DM send feedback** in `ConversationThread.tsx`: `Sending…` button text + `aria-busy`; optimistic message ghosts to 0.55 opacity; on send failure (HTTP error or network throw) the input is restored *and* a toast fires (`Couldn't send message. Try again.`). Previously the message silently disappeared.
- **Personal-email scrub:** `geoleith@gmail.com` removed from public-facing surfaces (`pricing`, `MediaFooter`, `MembershipPageClient` keynote inquiry fallback). All three now route through `support@evolvedpros.com` with subject prefills. The internal `scheduler/generate` server query — not a public exposure — is left alone.
- **Dead-code cleanup** on `/membership-expired`: the unused `checkoutUrl` with its `'#'` fallback is gone; the actual CTAs already point at `/membership` + `mailto:support`.

### UX-1 · Shared primitives — `4a87cbc`

Three reusable components in `apps/web/components/ui/`:

- **`Breadcrumb`** + **`BackLink`** — replaces hand-rolled `← Back to X` patterns scattered across events, podcast, and admin lesson edit. Final breadcrumb item carries `aria-current="page"`.
- **`EmptyState`** — icon + title + body + optional action. One canonical layout for the "no items yet" pattern.
- **`Modal`** — focus trap (Tab / Shift-Tab cycle), ESC handler, backdrop click, body-scroll lock, `useId`-generated `aria-labelledby`, focus restore on close. Optional `panelStyle` for surface overrides (used by the dark new-message modal).

### UX-2 · Modal focus trap rollout — `7f738ea`

`BannerPickerModal` and the new-message modal in `MessagesClient` now route through the `Modal` primitive. Both gain ESC handling, focus trap, focus restoration, body-scroll lock, and consistent `role="dialog"` / `aria-modal` semantics.

Side cleanup: stripped two stray `console.log` debug statements from `BannerPickerModal`; added an `sr-only` `<label>` to the new-message search input; replaced empty `alt=""` on banner thumbnails.

### UX-3 · `useReducedMotion` + OS preference honoured — `30161e5`

- New SSR-safe hook `apps/web/hooks/useReducedMotion.ts`.
- `ConfettiBlast` skips visual under reduced motion but still calls `onComplete` (so onboarding doesn't hang).
- `StreakCelebration` skips the confetti rain block — milestone card itself still renders.
- `globals.css` adds a defensive `@media (prefers-reduced-motion: reduce)` rule that neutralises any animation/transition we miss in components.

### UX-4 · Composer draft autosave — `b766200`

- New hook `apps/web/hooks/useDraft.ts` exposes `loadDraft<T>(key)`, `clearDraft(key)`, and `useDraftAutosave<T>(key, value, { isEmpty?, debounceMs? })`.
- `FeedCompose.tsx` round-trips `{ body, selectedTag, activePostType, pollOptions, pollClosesAt }` through `localStorage` on key `ep:draft:community:compose:<channelId>`. Per-channel scoping prevents drafts bleeding across channels.
- `clearDraft` fires alongside the existing reset on successful submit.

### UX-5 · Code-split podcast player — `444cd54`

`/podcast/[slug]` was synchronously importing `@mux/mux-player-react` (~200 kB) plus the wrapping `EpisodePlayer` component, giving a 389 kB First Load JS budget.

- New `apps/web/components/podcast/DynamicEpisodePlayer.tsx` mirrors the academy `DynamicMuxPlayer` pattern: `next/dynamic({ ssr: false, loading: <16:9 black poster> })`.
- Slug page swapped to `import { DynamicEpisodePlayer as EpisodePlayer }` — zero call-site changes.

**Build delta:**

| Metric | Before | After | Δ |
|---|---|---|---|
| `/podcast/[slug]` route bundle | 293 kB | 1.77 kB | −291 kB |
| `/podcast/[slug]` First Load JS | 389 kB | 97.9 kB | −291 kB (−75%) |

`marked` and `recharts` from the original audit didn't need splitting — `marked` is server-only on `/media/[pillar]/[slug]`, `recharts` isn't directly imported anywhere.

### UX-6 · Admin nav: platform-back link + mobile menu — `14ba5a4`

The QA report flagged two gaps in admin chrome: admins on desktop had no top-bar way to exit admin, and the nav tabs hid entirely below `md` with no mobile fallback.

- **Desktop:** new `← Platform` link in the right cluster of `AdminTopNav`, visible at all breakpoints (with hover state).
- **Mobile:** new hamburger trigger (`md:hidden`) opens the same sidebar nav inside a centered Modal — focus trap, ESC, backdrop click, body-scroll lock all included for free.
- **Refactor:** sidebar nav data extracted into a `SECTIONS` constant; reusable `<AdminSidebarNav onSelect?>` renders the contents and is consumed by both the desktop `<aside>` and the mobile modal.
- Outer `<aside>` now `hidden md:flex` so it doesn't squeeze the mobile main column.

### UX-7 · `next/image` migration + alt audit — `9b49557`

- `next.config.mjs`: added `images.unsplash.com` to `remotePatterns` (CSP already allowed it; this lets `next/image` proxy admin Unsplash picks).
- Migrated avatars on the highest-traffic surfaces (`LeaderboardRail`, `PostCard`, `PostCardV2`, `PodcastHero`) — fixed sizes 28 / 32 / 36 / 40 px.
- Variable-aspect images on those same surfaces got `loading="lazy" decoding="async"` (browser-native lazy loading; same perf benefit, no library swap).
- Alt-text upgrades throughout: `displayName` → `${displayName} avatar`; episode thumbnails labelled by role; `PostCardV2` had `alt=""` despite the image being meaningful — now names the author.

## Outstanding follow-up

Documented for future sprints — not landed:

1. **Full `next/image` sweep** — ~85 remaining `<img>` callsites (banners, ImagePicker grid, admin tools, BannerPickerModal preset banners). Pattern is documented inline in commit `9b49557`.
2. **Breadcrumb / BackLink rollout** — retrofit hand-rolled instances on `/events/[eventId]`, `/podcast/[slug]`, `/admin/courses/.../edit`, and crucially `/academy/[pillarSlug]/[lessonSlug]` (currently has no back navigation at all).
3. **EmptyState rollout** — notifications page, community feed, events list when empty.
4. **`useDraftAutosave` rollout** — `PostReplyThread`, top-level `Composer`, admin form pages.
5. **Per-route `error.tsx`** with section-specific copy (only the global one exists today).
6. **True mobile drawer for admin menu** — current is a centered modal; a left-slide drawer would feel more native, but it needs a generic `<Drawer />` primitive first.
7. **`pnpm.overrides` for `@types/react`** — fixes the persistent tsc resolution drift.
8. **Mux webhook HMAC verification** — flagged Critical in the original QA; still unauthenticated. Out of scope for this UX sprint but the highest-priority security item.
9. **CSS variables for hardcoded hex** — biggest "consistency multiplier" identified by the audit, deliberately deferred as its own sprint.
